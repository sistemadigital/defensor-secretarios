# sistema digital
Appweb HtmlSPA dedicada a la gestión judicial y administrativa de la Defensoría Oficial 6
Integra funcionalidades de registro, seguimiento, revision y agenda de eventos en los expedientes judiciales
donde interviene la Defensa Oficial

Principales Aplicativos:
1. Expedientes
2. Eventos
3. Documentos
4. Dictamenes
5. Notificaciones
6. Operador
7. Organismos
8. Sistema de proteccion de persona
9. Libros
10. Mapoteca
